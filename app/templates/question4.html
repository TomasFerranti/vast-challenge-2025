Visualization Guide

This boxplot visualization compares a person's sentiment patterns across different datasets (FILAH, TROUT, and complete journalist dataset). Each box represents an industry/dataset combination:

  • X-axis: Industry/Dataset combinations (e.g., "tourism (FILAH)", "small vessel (TROUT)")
  • Y-axis: Sentiment values (ranging from -1 to +1)
  • Box plots: Show the distribution of sentiment values for each combination
  • Colors: Different colors for each industry/dataset combination
  • Missing combinations: Not all people appear in all datasets

Analysis Questions:

  • How does the selected person's sentiment differ between datasets?
  • Are there consistent patterns across datasets or significant variations?
  • Which industries show the most variation in sentiment across datasets?
  • What story does each dataset tell about this person's behavior?
